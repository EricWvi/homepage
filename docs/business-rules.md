# 业务规则

本文描述 Homepage 的业务概念与规则，不涉及实现方式。

## 概念

| 概念 | 说明 |
| --- | --- |
| 用户 | 通过统一认证（Authelia）登录的人。每个用户拥有一套独立的分组、网站、域名和图标。 |
| 网站 | 一条收藏，由标题、链接和所属分组组成，可以带若干子链接。 |
| 子链接 | 同一网站下常用的其他页面，例如 GitHub 上的某个仓库。 |
| 分组 | 网站的归类。分为一个**默认分组**和任意多个**自定义分组**。 |
| 域名 | 网站链接中的主机名，例如 `https://github.com/golang` 的域名是 `github.com`。 |
| 图标 | 属于域名，而不是属于某个网站。同一域名下的所有网站显示同一个图标。 |

## 用户与登录

- 只有登录后才能查看和修改内容。未登录时打开主页会自动跳转到统一认证登录。
- 同一个人在统一认证中的账号始终对应同一个用户；在统一认证里修改显示名或邮箱，不影响已有数据，下次登录时显示名会随之更新。
- 用户之间的数据完全隔离：看不到、也改不了别人的分组、网站和图标。
- 新用户第一次登录时，自动拥有一个空的默认分组。
- **登录状态永久有效**：登录后无论多久不访问，都不需要重新登录，直到用户在主页上手动退出。
- **退出登录**：
  - 只退出当前浏览器，其他设备或浏览器上的登录不受影响。
  - 退出后，当前设备上缓存的该用户数据会被清除，离线时也无法再查看。
  - 退出后停在“已退出登录”页面，不会自动重新登录；点击“登录”才会重新进入统一认证。
  - 退出主页不会退出统一认证本身，若统一认证仍处于登录状态，再次登录可能无需输入密码。
- 离线时无法退出登录。

## 主页展示

- 页面背景为纯色，跟随系统亮色/暗色主题自动切换。两种主题都使用柔和的底色，不使用纯白或纯黑。
- 网站以大图标网格展示，图标下方显示标题，标题过长时截断。
- 展示顺序：
  1. 默认分组的网站排在最上方，**不显示分组标题**；默认分组为空时这一块不占位。
  2. 自定义分组按用户设定的顺序依次向下排列，每个分组先显示分组名，再显示该组的网站。
  3. 自定义分组没有网站时，仍显示分组名，并提示“暂无网站”。
- 同一分组内，网站按加入该分组的先后顺序排列。
- 既没有网站也没有自定义分组时，显示空状态和“添加网站”入口。
- 域名没有设置图标时，显示一个带网站标题首字母的色块。色块颜色由域名决定，同一域名颜色始终一致。
- 点击图标跳转到网站链接。
- 带子链接的网站，图标右下角显示子链接数量：
  - 鼠标在图标上停留片刻，图标下方弹出子链接列表，移开后自动收起；快速划过不会弹出。
  - 点击数量角标也会弹出列表，此时列表保持打开，可以用 ↑↓ 选择、Enter 打开，点击别处或按 Esc 关闭。
  - 列表中每一项显示标题和路径（标题就是路径时只显示一次），点击在当前标签页打开。

## 搜索

- 搜索框常驻在网站图标上方，打开主页时**不会**自动获得焦点。
- 焦点不在按钮、链接、输入框上，且没有打开对话框或菜单时，按 Enter 进入搜索框输入。
- 输入时，搜索框下方列出标题或链接包含全部关键词的网站和子链接，最多 8 条：标题以输入内容开头的排在最前，其次是标题包含输入内容的，最后是只有链接匹配的。没有匹配时不显示列表。用输入法组字时建议不随拼音变化，确认文字后才刷新。
- 用 Tab / Shift+Tab 或 ↑↓ 选中一条建议，按 Enter 在当前标签页打开它；没有选中任何建议时，按 Enter 用当前搜索引擎搜索输入内容，同样**在当前标签页**打开结果。内容为空时不搜索。输入法选词时按的 Enter 不触发搜索。
- 也可以直接点击建议打开。
- 没有搜索建议时，在搜索框中按 Tab 依次切换到下一个搜索引擎，Shift+Tab 切换到上一个，到末尾后回到开头；有建议时 Tab 用于选择建议，搜索引擎只能点击图标切换。按 Esc 离开搜索框。
- 当前搜索引擎的图标显示在搜索框左侧，点击图标可从列表中直接选择搜索引擎。
- 搜索引擎依次为：必应、谷歌、百度、朗文当代、翻译、GitHub、小红书、哔哩哔哩、知乎、豆瓣。
- 每次打开主页都从必应开始，不记住上次使用的搜索引擎。

## 网站

### 添加

- 填写三项：**标题**、**链接**、**分组**。分组默认选中默认分组。
- 标题必填，最多 200 个字符。
- 链接必填，只接受 `http` 和 `https` 地址。没写协议时按 `https` 处理，例如输入 `go.dev` 会保存为 `https://go.dev`。
- 新网站排在所选分组的末尾。
- 如果这个网站的域名之前从未出现过，系统会自动把该域名登记到图标管理中（此时还没有图标）。

### 编辑

- 可修改标题、链接、分组，校验规则与添加时相同。
- 换到另一个分组时，网站会移到新分组的末尾；分组不变则位置不变。
- 链接改到一个新域名时，同样会自动登记该域名。原域名不受影响。

### 子链接

- 在添加或编辑网站时维护，与网站的其他内容一起保存；可添加、删除、调整顺序，每个网站最多 50 个。
- 子链接必须与网站**同一域名**（同样按主机名精确区分），否则无法保存。网站的链接改到新域名时，原有子链接也必须随之修改。
- 链接可以只填路径，例如 GitHub 网站下填 `eric/palace`，会补全为 `https://github.com/eric/palace`；也可以填完整地址。
- 标题可选，不填时取路径的最后两段，例如 `eric/palace`；路径为空时取域名。不填标题的子链接，修改路径后标题会随之变化。

### 删除

- 删除前需要确认。
- 删除网站会一并删除它的子链接，但**不会**删除它的域名和图标；之后再添加同一域名的网站，会直接沿用原来的图标。

## 分组

- **默认分组**始终存在，固定在最上方，不能重命名、删除或调整位置。
- **自定义分组**：
  - 新建：名称必填，最多 100 个字符，新分组排在最后。
  - 重命名：规则与新建相同。
  - 排序：可上移、下移，调整的是它们在主页上的先后顺序。
  - 删除：需要确认；分组内的网站**不会被删除**，而是按原顺序移到默认分组末尾。
- 分组名允许重复。

## 域名与图标

图标管理是一个独立界面，列出所有登记过的域名，以及每个域名当前的图标和使用它的网站数量。

- **登记**：只有添加或编辑网站时出现新域名才会自动登记，不能手动登记。
- **上传 / 更换图标**：图标由用户提供，可选。支持 PNG、JPEG、GIF、WebP、ICO、SVG，单个文件不超过 2 MB。更换后，该域名下所有网站立即显示新图标。
- **移除图标**：域名保留，网站恢复显示首字母色块。
- **删除域名**：
  - 只有当没有任何网站使用该域名时才能删除，删除前需要确认。
  - 删除域名会同时删除它的图标。
  - 网站被删光的域名会继续留在列表中（标注“没有网站使用”），直到用户手动删除。
- 域名按主机名精确区分：`www.github.com` 和 `github.com` 是两个不同的域名，各有各的图标；大小写不区分；端口不影响域名。

## 离线与数据同步

- 打开过一次之后，再次打开主页会立即显示上次看到的内容，不需要等网络。离线时不需要重新登录。
- 断网时可以正常浏览和点击跳转，所有修改操作（增删改网站、分组、图标）都不可用，会提示当前处于离线状态。
- 页面会在打开时、切回该标签页时、网络恢复时自动获取最新数据。
- 系统发布新版本后，下一次打开页面时生效。
